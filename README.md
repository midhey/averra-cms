# Averra CMS

Лёгкая CMS студии для быстрых и аккуратных лендингов. Страница — данные из блоков по строгим схемам,
сайт собирается в статический HTML, нейронки работают с теми же схемами через MCP. У каждого
клиента своя установка на его VPS: студия её ставит и сопровождает.

**Документация — https://midhey.github.io/averra-cms/** (исходники — `apps/docs`): установка и
сопровождение, работа в админке, MCP, всё для разработчика, принятые решения и дорожная карта.

## Что умеет

- **Страницы из блоков** — 16 блоков от первого экрана до контактов и видео, редактор с живым
  предпросмотром на телефоне, планшете и десктопе, черновик, публикация и история версий.
- **Сайт без лишнего** — статический HTML, работает без JavaScript; картинки в AVIF и WebP, SVG
  очищаются при загрузке.
- **Тема, шапка и подвал** — шесть готовых тем со своими шрифтами и проверкой контраста, четыре
  раскладки шапки с меню, три вида подвала.
- **SEO** — настройки сайта и каждой страницы, проверки советами, разметка для поисковиков,
  sitemap.xml, редиректы, Метрика и GA4.
- **Заявки** — формы без JavaScript и без капчи, согласие по 152-ФЗ, уведомления в почту и
  Telegram, cookie-уведомление и политика из шаблона.
- **Нейронки** — MCP-сервер и токены API: читать блоки, тему и шапку, сохранять и
  публиковать страницы.
- **Сопровождение** — установка на VPS одной командой, обновление с бэкапом и откатом, бэкапы в
  S3, `pnpm fleet` для всех установок студии.

Что готово и что дальше — [дорожная карта](https://midhey.github.io/averra-cms/roadmap/).

## Быстрый старт

Нужен pnpm 12 — автономный или через corepack (`corepack pnpm …`). Corepack есть в Node 18–24;
в Node 25 и новее его нет — поставьте его отдельно (`npm i -g corepack`) или возьмите автономный
pnpm. Node для проекта ставить не нужно: pnpm сам скачает закреплённую Node 24 и запустит скрипты
на ней.

```bash
pnpm install
cp apps/api/.env.example apps/api/.env   # учебный владелец для pnpm dev
pnpm dev                                  # API :4000, админка :5173, сайт :4321
```

Вход в админку — `http://localhost:5173`, почта и пароль — `DEV_OWNER_*` из `apps/api/.env`.
Перед коммитом — `pnpm format`, `pnpm check` и, если менялись админка, API или рендерер, `pnpm e2e`.
Подробно — [Запуск](https://midhey.github.io/averra-cms/dev/).

## Что где

| Папка | Что |
|---|---|
| `apps/api` | API: Hono, Drizzle, PostgreSQL (локально PGlite), Better Auth |
| `apps/admin` | админка: React, Vite, `@averra/ui` |
| `apps/renderer` | сборка сайта: Astro |
| `apps/mcp` | MCP-сервер для нейронок |
| `apps/docs` | сайт документации: Astro Starlight |
| `packages/*` | схемы (Zod), блоки, токены темы, основа стилей админки |
| `deploy` | установка на VPS: Dockerfile, Compose, Caddy, `install.sh`, `averra.sh`, `pnpm fleet` |
| `e2e` | сквозные тесты на Playwright |

Правила для агентов, которые пишут код, — [AGENTS.md](AGENTS.md).
