Раздел для тех, кто работает с сайтом: клиента, редактора и студии. После этой страницы вы будете
знать, что можно вашей роли и где искать нужный экран.

Админка открывается по адресу `https://admin.<домен сайта>`. Регистрации нет: войти можно по
приглашению или с учётной записью, которую завела студия.

## Роли

| Что можно | Владелец | Редактор | Клиент |
|---|:-:|:-:|:-:|
| видеть сайт, страницы, историю, медиатеку | ✓ | ✓ | ✓ |
| править черновики страниц | ✓ | ✓ | ✓ |
| возвращать прошлую версию в черновик | ✓ | ✓ | ✓ |
| загружать картинки | ✓ | ✓ | ✓ |
| создавать, публиковать и удалять страницы | ✓ | ✓ | — |
| удалять картинки, «Собрать заново» | ✓ | ✓ | — |
| видеть и обрабатывать заявки, настраивать уведомления | ✓ | — | ✓ |
| выгрузить все данные сайта | ✓ | — | ✓ |
| скачать сайт архивом | ✓ | ✓ | ✓ |
| приглашать участников | ✓ | — | — |
| создавать сайты, почта, состояние установки | ✓ | — | — |

- **Владелец** — обычно студия. Видит все сайты установки.
- **Редактор** — подрядчик или контент-менеджер. Заявок не видит: персональные данные посетителей
  ему не нужны.
- **Клиент** — заказчик для повседневной работы: тексты, картинки, заявки. Публикует владелец или
  редактор.

Редактор и клиент видят только сайты, куда их пригласили. Чужой сайт для них выглядит как
несуществующий. То, что роли нельзя, админка не показывает, но решает всё равно сервер.

## Где что

Слева — боковая панель:

- **переключатель сайта** и разделы сайта: Обзор, Страницы, Медиатека, Заявки (со счётчиком
  новых), Настройки сайта;
- **«Установка»** — только у владельца: Почта (с состоянием) и Состояние (с версией);
- внизу — кто вошёл, его роль и «Выйти».

На телефоне панель открывается кнопкой «Меню». Редактор страницы — на весь экран, без панели.
