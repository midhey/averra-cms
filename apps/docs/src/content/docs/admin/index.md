Раздел для тех, кто работает с сайтом: администратора сайта, редактора и студии. После этой
страницы вы будете знать, что можно вашей роли и где искать нужный экран.

Админка открывается по адресу `https://admin.<домен сайта>`. Регистрации нет: войти можно по
приглашению или с учётной записью, которую завела студия.

## Роли

| Что можно | Владелец | Администратор сайта | Редактор |
|---|:-:|:-:|:-:|
| видеть сайт, страницы, историю, медиатеку | ✓ | ✓ | ✓ |
| создавать, править, публиковать и удалять страницы | ✓ | ✓ | ✓ |
| возвращать прошлую версию в черновик, «Собрать заново» | ✓ | ✓ | ✓ |
| загружать и удалять картинки | ✓ | ✓ | ✓ |
| ставить и заполнять свои блоки на страницах | ✓ | ✓ | ✓ |
| шапка и подвал: тексты, ссылки, меню, кнопка, логотип, тексты своего вида | ✓ | ✓ | — |
| вид шапки и подвала: раскладка, липкость, форма и наведение кнопки, меню на телефоне, фон и линии, свой вид | ✓ | — | — |
| раздел «SEO и аналитика»: индексация, адрес, счётчики, «Организация» (контакты и реквизиты), cookie-уведомление, редиректы | ✓ | ✓ | — |
| видеть и обрабатывать заявки, настраивать уведомления о них | ✓ | ✓ | — |
| выгрузить все данные сайта | ✓ | ✓ | — |
| описание и «скрыть от поисковиков» у своей страницы | ✓ | ✓ | ✓ |
| скачать сайт архивом | ✓ | ✓ | ✓ |
| приглашать и отключать редакторов | ✓ | ✓ | — |
| приглашать администраторов сайта, менять роли, второй владелец, передача владения | ✓ | — | — |
| менять и публиковать тему сайта | ✓ | — | — |
| создавать и публиковать свои блоки (поля, шаблон, CSS, скрипт) и скрипт сайта | ✓ | — | — |
| почта, состояние и обновление установки, каналы уведомлений | ✓ | — | — |
| токены MCP для нейронки («Доступ для ИИ») | ✓ | — | — |
| свой профиль: имя, пароль, выход на других устройствах | ✓ | ✓ | ✓ |

- **Владелец** — студия или интегратор, который поставил установку и отвечает за неё. Ему открыто
  всё: код своих блоков, тема, токены, обновление, участники. Владельцев может быть несколько.
- **Администратор сайта** — люди заказчика: контент, SEO, картинки, заявки и уведомления,
  контакты и реквизиты, тексты, ссылки и логотип шапки и подвала. Сам приглашает редакторов. Тему,
  вид шапки и подвала, свои блоки и установку не трогает: это делает студия.
- **Редактор** — пишет контент (на будущее — блог): страницы и картинки. Заявок не видит:
  персональные данные посетителей ему не нужны.

Почему тема и вид шапки и подвала только у владельца: это фирменный стиль, который делает студия,
и одна правка меняет каждую страницу сайта. Администратор сайта и редактор видят тему только для
чтения, администратор сайта — ещё и вид шапки и подвала.

Одна установка — один сайт ([почему](/averra-cms/decisions/single-site/)): администратора сайта и
редактора приглашают в установку, и они сразу работают с её сайтом. То, что роли нельзя, админка не
показывает, но решает всё равно сервер. Если открыть закрытый вашей роли раздел по адресу, будет
экран «Нет доступа к разделу» с причиной и ссылкой к обзору, а не сообщение об ошибке.

Экраны с формами ведут себя одинаково: «Сохранить» неактивна, пока нет правок; уйти с
несохранёнными правками (в другой раздел, закрытием вкладки или перезагрузкой) админка даст только
после вопроса; где карточек много (SEO), кнопка одна на весь экран. Так работают тема, шапка и
подвал, заявки, получатели уведомлений, форма Telegram-бота (набранный токен), SMTP, Cookie и
все карточки SEO. Поля паролей можно показать кнопкой-глазом справа (в том числе на экране входа).

Экраны, которые открываются только для чтения (тема — администратору сайта и редактору, шапка и
подвал — редактору; у администратора сайта на экране шапки и подвала только для чтения раскладка и
вид), остаются доступными по адресу: их видно, но не поменять. Закрытые целиком
(SEO, почта, доступ для ИИ, состояние, экран своего блока; список блоков виден) — экран «Нет
доступа к разделу «…»» с причиной.

## Где что

Слева — боковая панель:

- **название и домен сайта** — домен открывает опубликованный сайт в новой вкладке. Выбирать сайт
  не нужно: он у установки один;
- разделы сайта: Обзор, Страницы, Тема (владелец), Шапка и подвал (владелец и администратор
  сайта), Свои блоки и Скрипт сайта (владелец), Медиатека, Заявки (со счётчиком новых), Уведомления и SEO
  (владелец и администратор сайта), Настройки сайта;
- **«Установка»** — только у владельца: Почта (с состоянием), Доступ для ИИ (токены MCP) и
  Состояние (с версией);
- внизу — «Профиль» (имя, пароль, выход на других устройствах), кто вошёл, его роль и «Выйти».

Опасные действия (удалить, отозвать, отключить доступ, уйти без сохранения) админка спрашивает
своим окном: на кнопке — что именно случится («Удалить страницу», «Отключить доступ»), опасная
кнопка красная, фокус стоит на безопасной («Оставить», «Остаться»), Esc — отказ.

На телефоне панель открывается кнопкой «Меню». Редактор страницы — на весь экран, без панели.
