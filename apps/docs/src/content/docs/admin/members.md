Для владельца, который даёт доступ к сайту, и для того, кого пригласили. После страницы вы
пригласите участника, примете приглашение и будете знать, как поменять роль.

Участники — пользователи установки. Сайт у установки один
([почему](/averra-cms/decisions/single-site/)), поэтому редактор или клиент установки — это
редактор или клиент её сайта.

## Пригласить

«Настройки сайта» → «Участники» (только владелец): почта, роль — **редактор** или **клиент** —
и «Пригласить». Человек получит письмо со ссылкой.

- Ссылка одноразовая и действует 7 дней.
- Повторное приглашение того же адреса отзывает прежнее.
- Ниже — список приглашений с состоянием: ждёт, принято, отозвано, истекло. «Отозвать» у ждущих.
- Пригласить нельзя владельца (ему и так открыт сайт) и того, кто уже участник.
- Не больше 3 приглашений в час на один адрес и 50 в час от одного владельца.

Без почты приглашение не отправить — раздел «Участники» говорит об этом заранее. Сначала
[настройте почту](/averra-cms/install/mail/).

## Принять

По ссылке из письма открывается экран приглашения: сайт, роль и кто пригласил.

- **Новый человек** задаёт имя и пароль дважды — и сразу входит.
- **У адреса уже есть вход** — войти своим паролем прямо на экране или, если уже вошли, нажать
  «Принять приглашение».
- **Вошли под другим адресом** — «Выйти» и войти под тем, на который пришло приглашение.

После этого человек сразу попадает на обзор сайта со своей ролью. Ссылка принятая, отозванная
или истёкшая — экран скажет об этом и что делать дальше: попросить новое приглашение.

## Сменить роль или дать доступ без письма

Экрана для смены роли и снятия доступа пока нет — это делает студия командой на сервере:

```bash
cd /opt/averra
# дать доступ уже заведённому пользователю или поменять роль
docker compose exec api node dist/server/member-add.js --email anna@example.ru --role editor
```

id сайта не нужен: команда берёт сайт установки. Пригласить командой (письмо уйдёт через очередь):
`member-invite.js` с теми же `--email` и `--role`. Если владельцев несколько, добавьте
`--by <почта владельца>`. `--site <id>` нужен только в старой базе разработки, где сайтов
несколько. Все команды — [Команды](/averra-cms/dev/commands/).

Роль, выданная командой уже после приглашения, при его принятии не меняется.
