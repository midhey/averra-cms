Для владельца и редактора, частично — для клиента. После страницы вы создадите страницы,
разберётесь в обзоре сайта и будете знать правила адресов.

## Сайт

Одна установка — один сайт, как в WordPress ([почему](/averra-cms/decisions/single-site/)).
Выбирать сайт не нужно: после входа сразу открыт его обзор, а в боковой панели — его название и
домен. Сайт появляется сам при установке, сразу с главной страницей (черновик, не опубликована) и
темой по умолчанию; название — из `--site-name` установщика, по умолчанию домен.

Второму сайту клиента — своя установка. Несколько сайтов в одной установке — будущий модуль
мультисайта ([дорожная карта](/averra-cms/roadmap/)).

## Обзор сайта

Первый экран админки. На нём:

- когда сайт опубликован, есть ли неопубликованные правки и как прошла последняя сборка; упала —
  сообщение со ссылкой на подробности;
- **«Новая страница»** и **«Опубликовать правки»** (владелец и редактор). Вторая публикует страницы,
  у которых черновик ушёл вперёд опубликованной версии. Новые, ни разу не опубликованные черновики
  она не трогает;
- карточки: новые заявки, страницы, последняя сборка, бэкап — только те, для которых есть данные
  и которые видит ваша роль;
- таблица страниц с поиском и последние заявки.

В старой базе разработки, где сайтов несколько, владелец увидит на обзоре заметку «В базе есть и
другие сайты»: админка работает с созданным первым, остальные целы, но не видны.

## Страницы

Раздел «Страницы» — таблица с поиском: заголовок, адрес, опубликована ли, есть ли правки.
Здесь же форма «Новая страница» и «Удалить» (кроме клиента).

**Новая страница:** заголовок, адрес и шаблон — пустая или с первым экраном из каталога блоков.
Новая страница — только черновик: на сайт она попадёт после «Опубликовать». После создания
открывается её редактор.

**Адрес страницы** — часть ссылки на сайте: латиница в нижнем регистре и цифры, дефис только между
ними, до 64 символов: `o-nas`, `price-2026`. Занятый адрес не пройдёт — ошибка встанет у поля.
Адреса `api` и `500` заняты служебной частью сайта: `/api/` принимает заявки с форм, а страницу
`500` сервер не отдаёт. Страница с таким адресом, созданная раньше, остаётся в админке, но в карту
сайта не попадает и скрыта от поисковиков — перенесите её содержимое на другой адрес.

**Главная** — страница с адресом `index`, открывается по корню сайта. Удалить её нельзя.

**Страница 404** — служебная, с адресом `404`: её показывают на адресах, где страницы нет. В списке
она подписана «на адресах, где страницы нет». Нет своей — на сайте стандартная. Создать её можно
здесь или в разделе [«SEO»](/averra-cms/admin/seo/#страница-404).

**Удалить страницу** можно вместе со всей её историей. Если она была опубликована, сайт
пересоберётся без неё.

## Клиенту

Клиент правит черновики существующих страниц, а создавать, публиковать и удалять их не может:
страницу, которую он не может удалить, ему и создавать незачем. Публикует владелец или редактор.

## Адреса экранов

У каждого экрана свой адрес и заголовок вкладки: ссылку можно сохранить или отправить, а
обновление вкладки оставит на месте. Кривой адрес страницы — экран «Страница не найдена». id сайта в
адресах нет: сайт у установки один.

| Экран | Адрес |
|---|---|
| Обзор сайта | `/` |
| Страницы | `/pages` |
| Редактор страницы | `/pages/<адрес>` |
| Медиатека | `/media` |
| Заявки и заявка | `/leads`, `/leads/<id заявки>` |
| SEO (владелец) | `/seo` |
| Настройки сайта | `/settings` |
| Почта, Состояние (владелец) | `/mail`, `/status` |

Старые адреса с id сайта — `/sites/<id>/…` из закладок и прежних писем — ведут на те же экраны:
`/sites/<id>/pages` открывает `/pages`, вкладка (`?status=…`) и раздел (`#leads`) сохраняются.
