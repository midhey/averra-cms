Для владельца и редактора, частично — для клиента. После страницы вы создадите сайт и страницы,
разберётесь в обзоре сайта и будете знать правила адресов.

## Сайты

Первый экран админки — список доступных вам сайтов. Владелец видит все сайты установки и кнопку
«Новый сайт»: название — и сайт готов, сразу с главной страницей (черновик, не опубликована) и
темой по умолчанию.

На домене установки показывается один сайт — тот, что создал установщик. Как подключить второй —
[Домены и SSL](/averra-cms/install/domains/).

## Обзор сайта

Экран сайта по умолчанию. На нём:

- когда сайт опубликован, есть ли неопубликованные правки и как прошла последняя сборка; упала —
  сообщение со ссылкой на подробности;
- **«Новая страница»** и **«Опубликовать правки»** (владелец и редактор). Вторая публикует страницы,
  у которых черновик ушёл вперёд опубликованной версии. Новые, ни разу не опубликованные черновики
  она не трогает;
- карточки: новые заявки, страницы, последняя сборка, бэкап — только те, для которых есть данные
  и которые видит ваша роль;
- таблица страниц с поиском и последние заявки.

## Страницы

Раздел «Страницы» — таблица с поиском: заголовок, адрес, опубликована ли, есть ли правки.
Здесь же форма «Новая страница» и «Удалить» (кроме клиента).

**Новая страница:** заголовок, адрес и шаблон — пустая или с первым экраном из каталога блоков.
Новая страница — только черновик: на сайт она попадёт после «Опубликовать». После создания
открывается её редактор.

**Адрес страницы** — часть ссылки на сайте: латиница в нижнем регистре и цифры, дефис только между
ними, до 64 символов: `o-nas`, `price-2026`. Занятый адрес не пройдёт — ошибка встанет у поля.

**Главная** — страница с адресом `index`, открывается по корню сайта. Удалить её нельзя.

**Удалить страницу** можно вместе со всей её историей. Если она была опубликована, сайт
пересоберётся без неё.

## Клиенту

Клиент правит черновики существующих страниц, а создавать, публиковать и удалять их не может:
страницу, которую он не может удалить, ему и создавать незачем. Публикует владелец или редактор.

## Адреса экранов

У каждого экрана свой адрес и заголовок вкладки: ссылку можно сохранить или отправить, а
обновление вкладки оставит на месте. Кривой адрес сайта или страницы — экран «Сайт не найден» или
«Страница не найдена».

| Экран | Адрес |
|---|---|
| Список сайтов | `/` |
| Обзор сайта | `/sites/<id сайта>` |
| Страницы | `/sites/<id>/pages` |
| Редактор страницы | `/sites/<id>/pages/<адрес>` |
| Медиатека | `/sites/<id>/media` |
| Заявки | `/sites/<id>/leads` |
| Настройки сайта | `/sites/<id>/settings` |
| Почта, Состояние (владелец) | `/mail`, `/status` |
