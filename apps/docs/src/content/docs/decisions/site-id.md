Для разработчика: почему в модели данных с самого начала несколько сайтов.

## Решение

`site_id` есть в каждой таблице с контентом — страницы, история, медиа, заявки, письма, сборки —
с первого дня, даже пока сайт один.

## Почему

- Прикручивать несколько сайтов к модели, где их не было, очень больно: переписываются все запросы и
  права.
- Клиенту с двумя лендингами не нужен второй сервер.
- Права проверяются по сайту: чужой сайт для участника неотличим от несуществующего.
- Запросы фильтруют по сайту без лишних соединений, а удаление сайта каскадом чистит всё его.

## Чем платим

Лишняя колонка и индекс в каждой таблице. Домен в установке пока один — второй сайт на своём домене
подключается руками в Caddyfile.
