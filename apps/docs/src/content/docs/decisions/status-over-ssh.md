Для студии и разработчика: как `pnpm fleet status` узнаёт состояние установок и почему не через API.

## Решение

Владелец видит состояние в админке (`GET /api/status`, только он). Студия получает то же самое по
SSH: `averra.sh status --json` выполняет команду `status.js` в контейнере API. Нового токена и
открытого маршрута для студии нет.

## Почему

| | SSH и команда (выбрано) | Токен студии по HTTPS |
|---|---|---|
| Что нового открыто в интернет | ничего | маршрут, принимающий токен уровня установки |
| Секрет | ключ SSH — он и так нужен для обновлений | ещё по токену на каждую установку |
| Когда API лежит | работает: скажет «API не отвечает» и покажет бэкапы из файлов | не работает — ровно тогда, когда нужнее всего |
| Цена | у студии должен быть SSH | новый вид токена, выпуск, отзыв, хранение |

В ответе — только числа, времена и короткие причины: без адресов, путей, логинов и секретов. Версии
нет в открытых маршрутах: номер версии подсказывает, какие уязвимости пробовать.

## Чем платим

Студии нужен SSH-доступ к каждому серверу и `sudo` на `averra.sh`. Обзора состояния без SSH (например,
с телефона) нет.
