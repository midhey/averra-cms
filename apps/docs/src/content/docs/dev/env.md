Справочник для разработчика и студии. После страницы вы будете знать, какая переменная за что
отвечает, где её задают и что будет без неё.

Конфиг API читается только в `apps/api/src/config.ts` и проверяется схемой: кривое значение — API
не стартует и говорит, что не так, не печатая секретов. Шаблоны — `.env.example` в каждом
приложении, сами `.env` — в `.gitignore`.

## API (`apps/api/.env`)

### Основное

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `NODE_ENV` | `development` | `development`, `test` или `production`. На сервере — `production`: тогда обязательны `AUTH_SECRET`, `ADMIN_URL`, `API_URL`, а cookie — только по HTTPS |
| `PORT` | `4000` | порт API |
| `AUTH_SECRET` | — | подпись cookie, от 32 символов (`openssl rand -base64 32`). Без него — только [учебный режим](/averra-cms/dev/) |
| `ADMIN_URL` | `http://localhost:5173` | адрес админки: только с него принимаются запросы с cookie, на него ведут ссылки в письмах |
| `API_URL` | `http://localhost:<PORT>` | адрес API снаружи. Начинается с `https://` — cookie получают `Secure` |
| `TRUST_PROXY` | `false` | `true`, если перед API прокси, который сам ставит `X-Forwarded-For` (Caddy). Иначе заголовок перезаписывается адресом соединения |
| `AVERRA_VERSION` | `dev` | версия установки; в образ её кладёт сборка релиза |
| `DEV_OWNER_EMAIL`, `DEV_OWNER_PASSWORD` | — | владелец в пустой базе, только в учебном режиме; задаются вместе |

### Сайт установки

Одна установка — один сайт ([почему](/averra-cms/decisions/single-site/)). В пустой базе API
создаёт его при первом запуске сам (в учебном режиме — демо-сайт).

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `SITE_URL` | учебный режим — `http://localhost:4321`, иначе — | адрес опубликованного сайта, только origin. Его домен админка показывает в боковой панели; без `SITE_NAME` он же — название нового сайта; без своего адреса в разделе «SEO» — адрес для `canonical`, `og:url` и `sitemap.xml`. На сервере его собирает `compose.yaml` из `SITE_DOMAIN` |
| `SITE_NAME` | домен из `SITE_URL`, иначе «Мой сайт» | название сайта при первом запуске. Длиннее 80 символов — обрезается. Потом название живёт в базе, переменная его не меняет |

### База

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `DATABASE_URL` | — | PostgreSQL: `postgres://пользователь:пароль@хост:5432/база`, пул 5 соединений |
| `PGLITE_DIR` | `.data/pglite` | папка встроенного PGlite, если `DATABASE_URL` не задан |

### Медиатека и публикация

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `MEDIA_DIR` | `.data/media` | папка медиатеки |
| `MEDIA_MAX_BYTES` | `10485760` (10 МБ) | самый большой файл медиатеки |
| `PUBLISH_DIR` | — | папка собранных сайтов. Задана — «Опубликовать» собирает сайт; не задана — публикация только меняет базу |
| `PUBLISH_KEEP_RELEASES` | `5` | сколько версий сайта хранить, от 2 до 50 |
| `PUBLISH_TIMEOUT_SECONDS` | `300` | сколько ждать сборку, от 10 до 3600 |
| `PUBLISH_MAX_MEMORY_MB` | `768` | предел кучи процесса сборки, от 128 до 8192 |
| `RENDERER_DIR` | `apps/renderer` рядом с API | папка пакета рендерера |
| `STATE_DIR` | — | папка итогов бэкапов, обновлений и проверки новой версии от `averra.sh`. Не задана — бэкапов и обновления из админки нет |
| `REQUESTS_DIR` | — | папка заявок на обновление из админки: API кладёт в неё файл-заявку, обновляет хост. Не задана — кнопки «Обновить» нет. На сервере — `/data/requests` (`compose.yaml`) |

### Почта

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `MAIL_TRANSPORT` | по обстоятельствам | `smtp`, `file` или `off`. Не задано: есть `SMTP_HOST` — `smtp`; есть SMTP в админке — он; учебный режим — `file`; иначе выключена. `file` в проде не принимается |
| `SMTP_HOST` | — | сервер SMTP. Задан — окружение главнее админки |
| `SMTP_PORT` | `465` | порт |
| `SMTP_SECURITY` | из порта | `tls` (465) или `starttls` (587, 25); для другого порта — обязательно |
| `SMTP_USER`, `SMTP_PASSWORD` | — | вход на SMTP. Пароль не попадает в базу, логи и ответы |
| `MAIL_FROM` | — | адрес отправителя на своём домене, обязателен для SMTP |
| `MAIL_FROM_NAME` | `Averra CMS` | имя отправителя |
| `MAIL_DIR` | `.data/mail` | папка файлового ящика |
| `MAIL_MAX_ATTEMPTS` | `8` | попыток отправки, от 1 до 50 |
| `MAIL_RETENTION_DAYS` | `30` | через сколько дней удалять письма из очереди, сообщения из очереди уведомлений (`notification_outbox`, в том числе так и не ушедшие) и закрытые приглашения, от 1 до 3650 |
| `MAIL_ENCRYPTION_KEY` | — | ключ шифрования секретов из админки: пароля SMTP, токена бота Telegram и пароля его прокси. 32 байта в base64. Без него SMTP в админке только для чтения, а бота Telegram не сохранить; в учебном режиме — учебный ключ |
| `DEV_SMTP_CONNECT_PORT` | — | только учебный режим и e2e: SMTP из админки подключается к этому порту вместо 465 и 587 |
| `TELEGRAM_API_URL` | `https://api.telegram.org` | адрес Bot API для уведомлений: свой сервер Bot API или зеркало, если Telegram недоступен с VPS ([Telegram-бот](/averra-cms/install/telegram/)). Только `https://`; `http://` — для своего сервера Bot API на этой машине (`localhost`, `127.0.0.1`) или в сети docker (имя без точки) и в учебном режиме (e2e — фейковый Bot API) |

## Рендерер (`apps/renderer/.env`)

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `CMS_SITE_ID` | сайт установки | какой сайт собирать. Не нужен: только для другого сайта старой базы, при публикации его ставит API |
| `CMS_API_URL` | `http://localhost:4000` | адрес API |
| `CMS_LINKS` | `api` | куда ведут картинки и формы: `api` — на `CMS_API_URL`; `relative` — от корня сайта (так собирает публикация на сервере) |

## Админка

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `CMS_API_URL` | `http://localhost:4000` | куда прокси Vite отправляет `/api` в разработке |
| `ADMIN_PORT` | `5173` | порт dev-сервера админки |
| `VITE_AVERRA_VERSION` | — | версия, вшитая в сборку админки (`deploy/Dockerfile` передаёт `AVERRA_VERSION`): по ней «Состояние» после обновления предлагает обновить страницу. В разработке не задаётся |

|---|---|---|

## Установка на сервере

`/opt/averra/.env` ведёт установщик; переменные API на сервере задаёт `compose.yaml` из этих
значений.

| Переменная | Что задаёт |
|---|---|
| `AVERRA_VERSION`, `AVERRA_PREVIOUS_VERSION` | версия образов и прежняя (после обновления) |
| `AVERRA_API_IMAGE`, `AVERRA_WEB_IMAGE` | образы без тега, по умолчанию `ghcr.io/midhey/averra-api` и `averra-web` |
| `SITE_DOMAIN`, `ADMIN_DOMAIN`, `ACME_EMAIL` | домены и почта для Let's Encrypt |
| `OWNER_EMAIL` | владелец, которого создал установщик |
| `SITE_NAME` | название сайта для первого запуска API (`--site-name`, по умолчанию домен сайта). Потом название живёт в базе. `SITE_ID` прежних версий не ведётся и не нужен, но остаётся в `.env`: его читает прежний Caddyfile при откате обновления |
| `POSTGRES_PASSWORD`, `AUTH_SECRET`, `MAIL_ENCRYPTION_KEY`, `BACKUP_PASSPHRASE` | секреты; при повторном запуске не меняются |
| `BACKUP_KEEP` | сколько бэкапов хранить и не старше скольких дней, по умолчанию 7, от 1 до 365 |
| `BACKUP_S3_BUCKET`, `BACKUP_S3_ACCESS_KEY_ID`, `BACKUP_S3_SECRET_ACCESS_KEY` | внешнее хранилище бэкапов |
| `BACKUP_S3_ENDPOINT`, `BACKUP_S3_REGION`, `BACKUP_S3_PREFIX` | по умолчанию `https://storage.yandexcloud.net`, `ru-central1`, `averra/<домен сайта>` |
| `UPDATE_SOURCE` | откуда `averra.sh check-update` узнаёт о новых версиях: `github:владелец/репозиторий`, по умолчанию `github:midhey/averra-cms`; `off` — не проверять |
| `ADMIN_UPDATE` | `off` — обновление из админки выключено: path-юнит заявок выключается (юниты пишутся, но заявки никто не забирает), лежащая заявка удаляется, новые не принимаются. После смены — `averra.sh install-units` |

Переменные окружения процесса (не строки `.env`):

| Переменная | Где | Что задаёт |
|---|---|---|
| `GHCR_TOKEN`, `GHCR_USER` | `install.sh` | вход в ghcr.io без вопроса |
| `AVERRA_OWNER_PASSWORD` | `install.sh` | пароль владельца без вопроса |
| `AVERRA_READY_TIMEOUT` | `averra.sh update`, `restore` | сколько ждать готовности API, по умолчанию 180 секунд |
| `AVERRA_SYSTEMD_DIR` | `averra.sh install-units` | куда писать юниты systemd, по умолчанию `/etc/systemd/system` (свою папку задают тесты) |
| `AVERRA_SERVERS` | `pnpm fleet` | путь к списку серверов вместо `~/.config/averra/servers.txt` |
