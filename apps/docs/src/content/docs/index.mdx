Страница — это данные из блоков по схемам, а не HTML в базе. Из них собирается быстрый статический
сайт. Всё, ради чего в WordPress ставят плагины, — формы, медиа, почта, бэкапы — есть в ядре.
Нейронки работают с теми же схемами через MCP, с правами редактора, а заявки им закрыты.
