Для студии. После страницы вы будете знать, что открыто на каждом домене установки, как
продлеваются сертификаты и что проверить, если сайт не открывается.

## Два домена — две роли

| Адрес | Что там |
|---|---|
| `https://<домен сайта>` | опубликованная статика сайта из `/srv/sites/<SITE_ID>/current`. Из API открыт только приём заявок `/api/forms/*` |
| `https://admin.<домен сайта>` | админка (статика) и API под `/api` — один источник, поэтому cookie сессии без CORS |

Других путей API на домене сайта нет. Новый открытый путь сайта в API добавляется осознанно,
строкой в `deploy/Caddyfile`.

## Сертификаты

Caddy выпускает и продлевает сертификаты Let's Encrypt сам: почта — из `--email` установщика
(`ACME_EMAIL`), данные — в томе `caddy_data`. Для этого DNS обоих доменов должен вести на сервер,
а порты 80 и 443 — быть открыты. HTTP перенаправляется на HTTPS.

Не выпускается сертификат — почти всегда это DNS:

- записи ещё не разошлись (от минут до суток);
- у домена есть A или AAAA на чужой адрес — Let's Encrypt проверяет каждый, IPv6 первым;
- `docker compose logs caddy` покажет ответ Let's Encrypt.

## Заголовки и кеш

На обоих доменах — HSTS, `X-Content-Type-Options: nosniff`, `Referrer-Policy`. У админки ещё
`X-Frame-Options: SAMEORIGIN`: чужой сайт не покажет её в рамке.

| Что | Кеш |
|---|---|
| страницы сайта, `index.html` админки и её экраны (`/sites/…`) | `no-cache`: новая версия видна сразу |
| `/_astro/*` и картинки `/media/<uuid>/…` сайта | год, `immutable`: у них хеш или uuid в имени |
| `/assets/*` админки | год, `immutable`; нет файла — 404, а не `index.html` |

Страница сайта с адресом `media` (`/media/`) под правило картинок не попадает: оно точное.

## Сменить домен

Запустите установщик ещё раз с новым `--site-domain` (или `--admin-domain`) и прежними
остальными флагами. Он проверит DNS нового имени, запишет его в `.env` и применит. Секреты,
владелец и сайт сохранятся. Ссылки в письмах переедут сами: они ведут на `ADMIN_URL`, а его
compose собирает из `ADMIN_DOMAIN`. Адрес отправителя писем (`MAIL_FROM` или «Адрес отправителя»
на странице «Почта») от домена установки не зависит — его меняйте сами, если нужно.

## Второй сайт и www

На домене установки Caddy отдаёт один сайт — тот, что в `SITE_ID`. Второй сайт на своём домене или
`www.` пока добавляется строкой в Caddyfile руками; из админки это появится вместе с настройками
домена (модуль «SEO и настройки сайта» в [дорожной карте](/averra-cms/roadmap/)).
