Для студии с несколькими клиентами. После страницы вы одной командой увидите состояние всех
установок и обновите их по очереди.

## Список серверов

Файл `~/.config/averra/servers.txt` на машине студии, **вне репозитория**:

```bash
mkdir -p ~/.config/averra
cp deploy/servers.example.txt ~/.config/averra/servers.txt
```

Строка на сервер:

```
<имя> <пользователь@хост> [port=<порт SSH>] [dir=<папка установки>]
remont   root@203.0.113.10
okna     deploy@okna.example.ru port=2222
```

Другой список — `--file <путь>` (относительный путь — от папки, где запущен `pnpm`) или переменная
`AVERRA_SERVERS`.

**Не кладите список в `deploy/`**: файлы оттуда уезжают на серверы клиентов, а список раскрыл бы
клиенту адреса остальных установок. На случай ошибки `servers.txt` есть в `.gitignore` и
`.dockerignore`.

## Доступ

SSH только по ключам (`BatchMode`): пароль не спрашивается, неизвестный ключ хоста — отказ, а не
вопрос. Поэтому первый вход на новый сервер — руками, `ssh root@…`, со сверкой отпечатка.
Пользователю нужен root или `sudo` без пароля для `/opt/averra/averra.sh`.

## Состояние всех установок

```bash
pnpm fleet status
```

Таблица: версия, база, бэкап, сборки, почта, место и проблемы — по `averra.sh status --json` на
каждом сервере. Код выхода 1, если где-то проблема или сервер не ответил.

Состояние идёт по SSH, а не токеном по HTTPS: в интернет ничего нового не открыто, и работает,
даже когда API лежит ([почему](/averra-cms/decisions/status-over-ssh/)).

## Обновление всех установок

```bash
pnpm fleet update --version 0.2.0               # все по очереди
pnpm fleet update --version 0.2.0 --only remont # только эти (через запятую)
```

По одной, первая ошибка останавливает обход. В конце — что обновлено, где сломалось и что не
трогали.

Обрыв SSH или Ctrl+C посреди обновления не бросает сервер на полпути: обновление на нём идёт
отдельно от SSH и доработает само. Итог — `pnpm fleet status`, а повтор `pnpm fleet update`
покажет ход идущего обновления или доведёт оборвавшееся. Подробно — [Обновления и
откат](/averra-cms/install/updates/).
