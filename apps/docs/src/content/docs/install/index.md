У каждого клиента своя установка Averra на его VPS. Студия её ставит, обновляет и следит за ней,
клиент работает в своей админке.

## Что входит в установку

PostgreSQL, API и Caddy в Docker Compose. Caddy сам выпускает сертификаты, «Опубликовать» собирает
сайт прямо на сервере.
