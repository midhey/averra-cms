Для студии перед новой установкой. После страницы у вас будет готовый сервер и DNS, на которых
установщик пройдёт с первого раза.

## Сервер

- **Ubuntu 22.04 или 24.04**, чистый. Процессор — amd64 или arm64: образы собираются под оба.
- **Память 1–2 ГБ.** Самое тяжёлое — сборка сайта при публикации: отдельный процесс с пределом
  кучи 768 МБ. Замер демо-сайта — около 300–350 МБ.
- **Диск** — с запасом под образы, базу, медиатеку, пять версий сайта и неделю бэкапов; для
  лендинга ориентир — 10 ГБ свободных. Меньше 1 ГБ или 10 % свободного места — [проблема в
  состоянии](/averra-cms/install/status/).
- **root** или `sudo`.
- **Порты 80 и 443** свободны: их займёт Caddy.
- **Docker с Compose v2.** Нет — установщик поставит пакеты Ubuntu `docker.io` и
  `docker-compose-v2` по флагу `--install-docker`.
- **systemd** — для ежедневного бэкапа по таймеру и обновления, отвязанного от SSH. Без него
  установщик подскажет строку для cron, а обновление пойдёт через `setsid`.

Клиентам из России сервер нужен в России: в заявках персональные данные посетителей
([152-ФЗ](/averra-cms/install/personal-data/)).

## DNS

Два имени, оба на IP сервера:

| Имя | Запись | Зачем |
|---|---|---|
| `example.ru` | A на IPv4 сервера | сайт |
| `admin.example.ru` | A на IPv4 сервера | админка и API |

**AAAA-записи** — только на IPv6 этого сервера или никаких. Let's Encrypt проверяет каждый адрес
домена, IPv6 — первым, и лишняя AAAA от панели регистратора сорвёт выпуск сертификата. Установщик
это проверяет и откажет, если какая-то запись ведёт не на сервер.

Поддомен админки можно взять другой — флаг `--admin-domain`.

## Доступы студии

- **SSH по ключу** с root или `sudo` без пароля для `/opt/averra/averra.sh` — им пользуется
  [`pnpm fleet`](/averra-cms/install/fleet/). Первый вход — руками, со сверкой отпечатка ключа
  сервера.
- **Доступ к образам** не нужен: образы `averra-api` и `averra-web` в GHCR публичные и
  скачиваются без входа. Токен GitHub (только `read:packages`) нужен, лишь если вы ставите свои
  закрытые образы или пакеты ещё не переключены в Public — флаг `--ghcr-user` в
  [установке](/averra-cms/install/server/). Docker хранит этот токен на сервере в
  `/root/.docker/config.json` в base64, без шифрования, — поэтому только `read:packages`.
- **Почта для Let's Encrypt и входа владельца** — например, `studio@example.com`.
- **SMTP-ящик** на домене, с которого пойдут письма, — понадобится после установки
  ([Почта](/averra-cms/install/mail/)).
