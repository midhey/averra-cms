Для студии и разработчика, которые хотят собирать и править лендинги нейронкой. После страницы вы
будете знать, что ей доступно, а что нет, и почему.

Нейронка — такой же клиент API, как админка. Она работает через MCP-сервер `apps/mcp` с теми же
схемами блоков и входит **токеном API с правами редактора на сайте установки**. Сайт у установки
один, поэтому id сайта нейронке знать не нужно. Особых путей для неё в API нет: всё, что она
присылает, проверяется так же, как правка из админки.

## Что умеет

| Инструмент | Что делает |
|---|---|
| `list_blocks` | каталог блоков: схемы полей, примеры и правила сборки страницы и её SEO |
| `list_sites` | сайт токена: id и название. Остальным инструментам id не нужен |
| `get_page` | черновик и опубликованная версия страницы; SEO — в `draft.seo` и `published.seo`, советы по SEO черновика — в `seoChecks` |
| `save_draft` | сохранить черновик страницы целиком: заголовок, все блоки и SEO страницы (`seo`). В ответе — `seoChecks`. Сайт не меняется |
| `publish_page` | опубликовать черновик — как «Опубликовать» у редактора |
| `get_theme` | тема сайта: цвета, шрифты и скругления — подбирать тексты и картинки под стиль. Только чтение |
| `get_header` | шапка и меню сайта: раскладка, пункты меню и куда они ведут — чтобы не ломать меню правкой страниц. Только чтение |
| `list_custom_blocks`, `get_custom_block` | определения своих блоков и инструкция, как их писать — с правом токена на черновики видны и черновики |
| `save_custom_block_draft`, `check_custom_block` | сохранить **черновик** определения своего блока и проверить его: замечания со строками и HTML, как на сайте. Публикует блок человек |

Подробно о входах и ответах — [Инструменты](/averra-cms/mcp/tools/).

Сценарии, для которых это сделано: черновик лендинга по брифу, «перепиши тексты под другую
аудиторию», правка одного блока, форма заявки с нужными полями.

## Чего не умеет

- **Заявки.** Ни прочитать, ни выгрузить: в них персональные данные посетителей. Токену эти
  действия запрещены отдельной проверкой (403), что бы ни стояло в таблице прав.
- **Полная выгрузка данных сайта** — по той же причине.
- **Загрузить картинку.** Нейронка ставит картинку только из медиатеки сайта (`mediaId` и
  обязательный alt). Пополняют медиатеку люди в админке.
- **История версий** — инструментов для неё пока нет, хотя права у токена есть.
- **Пригласить участника, почта, состояние установки** — только владелец в админке. Создавать
  сайты не может никто: сайт у установки один, его создаёт установка.
- **Чужие сайты** (в старой базе разработки) — токен привязан к одному сайту, остальные для него не
  существуют (404).

## Сломать вёрстку нельзя

Входные схемы инструментов — те же Zod-схемы, что проверяют страницы в API. Лишнее поле, кривой
адрес, картинка чужого сайта, форма без ссылки на политику — API ответит ошибкой с путём до поля,
и нейронка исправит. Страница, которую API принял, соберётся.

## Публикует ли нейронка

Да: у токена права редактора, и `publish_page` публикует сразу. Если хотите, чтобы публиковал
человек, просите нейронку только сохранять черновик и публикуйте сами из админки. Токен «только
черновики» — в [дорожной карте](/averra-cms/roadmap/).
