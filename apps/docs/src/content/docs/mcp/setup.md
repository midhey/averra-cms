Для разработчика и студии. После страницы нейронка в Claude Code (или другом MCP-клиенте) будет
видеть сайт и сможет собирать его страницы.

MCP-сервер Averra — процесс на вашей машине, клиент API по stdio. Он ходит в API по адресу
`CMS_API_URL` с токеном `CMS_API_TOKEN`: в локальный `pnpm dev` или в установку клиента.

## Локально, с `pnpm dev`

1. Остановите `pnpm dev`: команде нужна база, а встроенная база не выдерживает два процесса.
2. Выпустите токен на нужный сайт (id виден в адресе админки `/sites/<id>`):

   ```bash
   pnpm token:create --site <id сайта> --name mcp
   ```

   Токен показывается один раз.
3. Скопируйте `apps/mcp/.env.example` в `apps/mcp/.env` (он в `.gitignore`) и вставьте строку
   `CMS_API_TOKEN=…` из вывода команды.
4. Запустите `pnpm dev`, откройте новую сессию Claude Code в папке репозитория и разрешите сервер
   `averra`. Был запущен — перезапустите: токен читается при старте.

Сервер описан в `.mcp.json` в корне репозитория и запускается на Node, закреплённой в проекте.
Путь к ней в `.mcp.json` записан под Windows (`node_modules/.bin/node.exe`); на macOS и Linux
поправьте его у себя на свою Node 24. stdout сервера занят протоколом MCP, поэтому запускайте его
напрямую через Node, а не через `pnpm run`: pnpm печатает в stdout свои строки.

## С установкой клиента

MCP-сервер можно направить в API установки — админка и API живут на одном адресе:

1. Выпустите токен на сервере:

   ```bash
   cd /opt/averra
   docker compose exec api node dist/server/token-create.js --site <id сайта> --name mcp
   ```

2. В `apps/mcp/.env` на своей машине:

   ```bash
   CMS_API_URL=https://admin.example.ru
   CMS_API_TOKEN=cms_…
   ```

3. Перезапустите MCP-сервер.

Публикация через MCP на установке собирает сайт на сервере, как публикация из админки.

## Переменные

| Переменная | Что задаёт |
|---|---|
| `CMS_API_TOKEN` | токен API. Без него сервер стартует, `list_blocks` работает, а остальные инструменты отвечают, как получить токен |
| `CMS_API_URL` | адрес API, по умолчанию `http://localhost:4000` |

Файл — `apps/mcp/.env`: сервер ищет его рядом с пакетом, а не в текущей папке.

## Проверка

Попросите нейронку вызвать `list_sites`: в ответе — сайт токена. Ошибки по-русски объясняют, что
не так:

- «Нужен токен API…» — `CMS_API_TOKEN` пуст;
- «API не принял токен: он отозван или неверный» — выпустите новый;
- «API не отвечает» — API не запущен или `CMS_API_URL` не тот.
