## Одна схема — много потребителей

Блок описан один раз: схема и компонент. Из схемы получаются проверка в API, форма в админке и
описание для нейронки.

## Путь страницы

Черновик в админке → публикация → сборка статического сайта на сервере → новая версия сайта без
простоя.

## Части системы

- **API** — данные, права, публикация.
- **Админка** — редактор и всё остальное для людей.
- **Рендерер** — собирает сайт в HTML и CSS.
- **MCP-сервер** — доступ для нейронок поверх API.

## Где живут данные

Страницы, заявки и медиа лежат на сервере клиента, а не у студии. Подробнее — в разделе
[Установка и сопровождение](/averra-cms/install/).
