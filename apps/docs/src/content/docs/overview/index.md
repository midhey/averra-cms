Averra — CMS студии для быстрых и аккуратных лендингов. Контент хранится как данные по схемам,
сайт собирается в статический HTML, а у каждого клиента своя установка на его сервере.

## Для кого

- **Студия** ставит установку клиенту, делает сайт и сопровождает его.
- **Клиент** работает в своей админке: тексты, картинки, заявки, возврат прошлой версии в
  черновик. Публикует владелец или редактор.
- **Нейронка** собирает лендинг через MCP с правами редактора на одном сайте. Заявки ей закрыты.

## Что есть в ядре

Страницы из блоков с живым предпросмотром, медиатека, формы и заявки, почта, история публикаций,
выгрузка сайта архивом. Подробнее — в разделе [Работа в админке](/averra-cms/admin/).

## Чего нет и не будет

Свободного холста, плагинов и маркетплейса, интернет-магазина. Почему — в разделе
[Решения](/averra-cms/decisions/).
