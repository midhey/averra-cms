Страница для всех, кто впервые слышит об Averra. Прочитав её, вы поймёте, что это за система,
кто с ней работает и куда идти дальше.

Averra — CMS студии для быстрых и аккуратных лендингов. Страница хранится как данные: список
блоков с полями по строгим схемам. Из них собирается статический сайт — HTML и CSS почти без
JavaScript. У каждого клиента своя установка на его сервере: студия её ставит и сопровождает,
клиент работает в своей админке. Как в WordPress, одна установка — один сайт: зашли на домен
админки — и сразу работаете с ним.

## Кто с ней работает

| Кто | Что делает |
|---|---|
| **Студия** (владелец установки) | ставит Averra клиенту, собирает сайт, обновляет установку, следит за бэкапами и почтой |
| **Клиент** | правит тексты и картинки, работает с заявками, возвращает прошлые версии в черновик |
| **Редактор** | подрядчик или контент-менеджер: страницы, картинки, публикация. Заявок не видит |
| **Нейронка** | собирает и правит страницы через MCP с правами редактора на сайте. Заявок не видит |

Подробно о ролях — [Роли и разделы](/averra-cms/admin/).

## Что есть в ядре

Всё, ради чего в WordPress ставят плагины, сделано в самой системе:

- страницы из блоков с живым предпросмотром на тех же компонентах, что и сайт;
- медиатека: картинки режутся под нужные ширины и кодируются в AVIF и WebP, метаданные удаляются;
- формы заявок без JavaScript, антиспам без капчи, согласие на обработку персональных данных;
- почта через очередь с повторами и проверкой SMTP по шагам;
- история публикаций и возврат любой версии в черновик;
- установка на VPS одной командой, обновления с откатом, проверенные бэкапы;
- выгрузка сайта архивом и всех данных сайта — клиент не заложник студии.

## Чего нет и не будет

- Свободного холста, как Zero Block в Тильде: страница собирается из готовых секций.
- Плагинов и маркетплейса: новое добавляется модулями в коде.
- Интернет-магазина, комментариев, форумов и поиска по сайту.

Почему так — в разделе [Решения](/averra-cms/decisions/).
